# Research context projection

The provider prompt shares exact repeated calculation subtrees, then exact repeated
field-name/value pairs. The second layer helps when calculations differ in one
field but otherwise repeat the same data. Descriptive names remain in the catalog;
amounts, assumptions, evidence IDs, rationale and variation lineage are not merged
by economic similarity.

For reconstruction, insert each `shared_field_refs` catalog pair into its containing
object, recursively; then resolve the existing `calculation_context_ref` aliases.
The catalog note explains both steps to the model. Source-owned reserved keys at
any depth disable field projection. Projection is deterministic, applied only if
smaller, and does not alter original saved sources, reports, calculations or tool
arguments. Existing assistant/tool messages remain intact.

Offline round-trip tests establish data preservation, not model understanding or
investment quality. The blocked November26 lead snapshot is also measured through
the actual agent middleware with the model boundary intercepted: no HTTP request.
Any new runtime needs its own immutable identity and approval. Reduced context does
not authorize reopening a canceled run, increasing its limits, or treating an
unresolved economic objection as resolved.

An explicitly admitted `reviewed_synthesis` descendant uses a tool-free, durable
lead with the same model budget and checkpoint journal. Its dated analytical
addendum and independent review are separate untrusted inputs, retained in the
result. They neither replace inherited reports nor clear their material-gap flags.
The original BUY/ADD veto remains enforced; any new decision still requires its
own economic review. Measure the complete new request, including addendum and
provenance, before admission; a smaller old request is not sufficient proof.

A reviewed revision additionally selects its model view: superseded acquisition
hypothesis, older portfolio thesis and obsolete navigation/checklist fields stay
in the immutable audit but are omitted from the new prompt. This is explicitly
not lossless compression; the prompt discloses each omitted path and exact value
hash. Current portfolio/reference, every full calculation, all reports/addendum,
previous rejected decision/review, arithmetic and the pre-selection evidence index
remain intact. Ordinary synthesis is unchanged. Before revision dispatch the
actual effective system prompt must match the independently approved new hash
and differ from the prior prompt. Tool-free synthesis does not append instructions
to use unavailable Robinhood research tools.
